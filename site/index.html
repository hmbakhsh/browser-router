01 / Install

One command,
then one permission.

Terminal
brew install --cask hmbakhsh/tap/browser-router

Browser Router lives quietly in your menu bar. macOS asks once before making it the default handler for web links.

02 / Configure

Guided by CLI.
Defined by JSON.

$ browser-router setup $ browser-router config $ browser-router validate $ browser-router default

Setup discovers installed Chromium browsers and their real profile names. Your rules remain readable at ~/.browser-router/config.json.

Precise when you need it

Match a host.
Narrow by path.

Rules run top to bottom. The first match wins; everything else opens in your default profile. 

{
  "defaultProfile": "Personal",
  "rules": [{
    "name": "Acme GitHub",
    "profile": "Work",
    "enabled": true,
    "match": {
      "host": "github.com",
      "pathPrefix": "/acme",
      "includeSubdomains": false
    }
  }]
}
